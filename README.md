## YTNotifer

YTNotifier は YouTube チャンネルの更新をバックグラウンドで見張り、  
動画・Short・ライブ・プレミアの公開をリアルタイムに近い形で通知するデスクトップアプリです。

<img width="674" height="375" alt="image" src="https://github.com/user-attachments/assets/d30ee581-6f1d-42c5-9008-e390bdcf8227" />

### 〇主な機能・特徴
- **動画・Short・ライブ・プレミアを個別に通知ON/OFF**
- **ライブ・プレミアの開始前通知** 
- **時間帯に応じた監視頻度の調整** 
- **チャンネルをカテゴリで整理** 
- **通知スタイル・通知音・テーマをカスタマイズ** 
- **動画のAI要約表示**（Gemini連携） 
- **プラグインで機能拡張** 
- **設定のバックアップ・復元** 

### 〇動作環境
- **対応OS**：Windows 10（バージョン1809以降）／Windows 11
- **配布形式**：単一の実行ファイル（`YTNotifier.exe`）。.NETランタイム同梱の自己完結型なので、別途ランタイムをインストールする必要はなく、置くだけで起動可能
- **必要なもの**：YouTube Data API v3 のAPIキー（初回起動時のセットアップウィザードで設定）
